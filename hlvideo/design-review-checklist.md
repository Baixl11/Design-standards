# 视频取证工具 Design Review Checklist

## 1. 采集来源检查

- [ ] 页面设计是否基于 `design-spec.md` 中列出的真实来源？
- [ ] 是否区分了真实采集、观察估算和适配建议？
- [ ] 是否存在未说明来源的精确色值、字号、间距或圆角？
- [ ] 是否把播放器暗色风格误用到了主工具浅色工作台？
- [ ] 是否遗漏了当前页面对应的参考视觉稿或 PRD 说明？

## 2. 整体风格检查

- [ ] 主工具是否保持浅色、专业、数据密集、取证可信的工作台气质？
- [ ] 页面是否避免了营销化大卡片、过度渐变和无意义装饰？
- [ ] 信息层级是否清晰，主操作、状态、结果是否一眼可辨？
- [ ] 复杂页面是否通过导航、分组、筛选、表格和详情区组织，而不是堆叠内容？
- [ ] 播放器页面是否仅在播放器场景中使用暗色沉浸视觉？

## 3. 色彩检查

- [ ] 主蓝色是否使用 `#2194FF` 或 token 中定义的蓝色？
- [ ] 报告/打印等深蓝按钮是否使用 `#3067F2` 或对应 token？
- [ ] 页面背景是否使用浅灰蓝或白色，而不是纯灰脏底？
- [ ] 文本是否按 `#303133`、`#606266`、`#909399`、`#C0C4CC` 分层？
- [ ] 边框是否使用 `#DCDFE6`、`#E4E7ED`、`#EBEEF5`？
- [ ] 成功、警告、错误、信息状态色是否统一？
- [ ] 是否存在未定义的新颜色？

## 4. 字体检查

- [ ] 是否使用 `Microsoft YaHei` 优先的字体栈？
- [ ] 默认正文、表格、按钮是否以 14px 为主？
- [ ] 辅助信息是否使用 12px 或 13px？
- [ ] 页面标题是否使用 18px 或 20px，报告标题是否可使用 24px 或 28px？
- [ ] 主工具内是否避免使用播放器首页级别的大标题？
- [ ] 字重是否以 400 和 700 为主，避免混入太多无规则字重？
- [ ] 数字、时间、路径等内容是否清晰可读？

## 5. 间距检查

- [ ] 页面间距是否遵循 4px/8px 系列？
- [ ] 页面安全边距是否约为 16px 或 24px？
- [ ] 卡片内边距是否为 12px、16px 或 24px？
- [ ] 表单项间距是否一致？
- [ ] 表格单元格间距是否保证可读且不过松？
- [ ] 顶部栏、侧边栏、工具栏是否与设计基准一致？
- [ ] 是否存在临时写死的奇怪间距值？

## 6. 圆角与阴影检查

- [ ] 主工具按钮、输入框、卡片是否主要使用 2px、3px、4px、6px 或 8px 圆角？
- [ ] 是否避免在主工具中滥用 12px 以上大圆角？
- [ ] 普通容器是否优先使用细边框而非重阴影？
- [ ] 浮层、下拉、弹窗阴影是否克制？
- [ ] 阴影颜色是否保持低透明度，不产生脏黑块？
- [ ] 圆角和阴影是否使用 token，而不是页面级散写？

## 7. 组件一致性检查

- [ ] Button 是否包含 default、hover、active、disabled、loading 状态？
- [ ] Button 文本是否不重叠、不挤压、不异常换行？
- [ ] 桌面图标按钮点击区是否不小于 32px？
- [ ] Web/触控原型按钮点击区是否不小于 44px？
- [ ] Input/Select focus 是否使用蓝色边框并保持同色系？
- [ ] Table 是否支持排序、选择、分页、横向滚动或列省略？
- [ ] Card 选中态是否是浅蓝底 + 蓝边框 + 明确选中图标？
- [ ] Modal 是否有遮罩、标题、内容区、底部操作区？
- [ ] Tabs 激活态是否使用蓝色文字或蓝色底部线？
- [ ] Tag 状态色是否与成功、警告、错误、信息 token 对应？
- [ ] Empty 是否有图标/说明/操作入口，不占用过多首屏空间？
- [ ] Loading 是否展示进度或等待文案？
- [ ] Sidebar 激活项是否清楚，长名称是否省略？
- [ ] Topbar 角标是否不遮挡图标和正文？

## 8. 页面布局检查

- [ ] 主工具是否保持顶部标题栏、左侧导航、工具栏、内容区的基本结构？
- [ ] 扫描结果页是否包含筛选条、表格、底部批量操作？
- [ ] 视频分析页是否优先保证播放器区域尺寸？
- [ ] 任务列表是否按最近发起时间排序，并展示进度、百分比和操作？
- [ ] 导出配置是否清楚区分保存位置、保存方式、更多设置、编码格式？
- [ ] 设置页是否清楚区分 AI 引擎状态和配置字段？
- [ ] 报告阅读器是否左目录、右内容，分页和打印入口明确？
- [ ] 弹窗内容过高时是否内容区滚动，底部按钮固定？

## 9. 交互状态检查

- [ ] hover 状态是否使用浅蓝或浅灰底，不造成布局位移？
- [ ] active 状态是否与主色同体系？
- [ ] selected 边框是否使用 `#2194FF` 或同体系蓝色？
- [ ] hover/selected 边框是否避免突兀高对比描边？
- [ ] disabled 状态是否明确不可点击？
- [ ] 错误状态是否提供原因和下一步操作？
- [ ] 任务进行中是否防止重复发起？
- [ ] 导出、扫描、AI 识别等长任务是否展示进度？
- [ ] 成功后是否有打开、查看或返回结果入口？
- [ ] 右键菜单、下拉菜单、tooltip 是否不遮挡核心正文？

## 10. 响应式与尺寸检查

- [ ] 1366x768 下是否完整可用？
- [ ] 1440x900 下是否显示正常？
- [ ] 1920x1080 下内容是否合理扩展？
- [ ] 1280x720 下是否有降级策略，如侧边栏折叠或表格横向滚动？
- [ ] 是否避免横向溢出导致关键按钮不可见？
- [ ] 多列表格是否有横向滚动、固定列、列省略或详情面板？
- [ ] 弹窗底部按钮是否在 1366x768 下可见？
- [ ] 长文件名、长路径、任务名是否不重叠、不挤压？
- [ ] 红色角标、状态徽标是否不覆盖正文？
- [ ] 是否经过截图或视觉检查确认，而不只是看代码？

## 11. 代码实现检查

- [ ] 是否优先使用 `design-tokens.md` 中的 CSS variables 或 Tailwind theme？
- [ ] 是否避免硬编码颜色？
- [ ] 是否避免硬编码字号？
- [ ] 是否避免硬编码间距和圆角？
- [ ] 新增组件是否复用 Button、Input、Table、Modal、Tag 等已有变体？
- [ ] 是否把主工具 token 和播放器 token 分开？
- [ ] 是否存在同一语义状态使用多个颜色的问题？
- [ ] 是否存在多个页面重复定义相同样式的问题？
- [ ] 是否为长文本提供 `ellipsis`、`title`、tooltip 或详情展开？
- [ ] 是否为高频交互组件补齐 hover、active、disabled、loading？

## 12. 设计验收流程

1. 对照目标页面选择参考视觉稿或 PRD 页面。
2. 检查页面是否使用正确主题：主工具浅色、播放器暗色。
3. 检查 token 使用情况，清理临时颜色、字号、圆角、阴影。
4. 截图检查 1366x768、1440x900、1920x1080。
5. 专门检查按钮大小、文字重叠、横向溢出、角标覆盖、选中边框突兀。
6. 检查表格长字段和弹窗底部按钮。
7. 按本清单逐项勾选，未通过项先修复再进入下一页面。

## 13. AI Coding 自检提示词

请在完成页面后，严格使用本 checklist 自检。

重点检查：

1. 是否使用视频取证工具浅色工作台设计规范。
2. 是否复用了 `design-tokens.md`。
3. 是否在 1366x768 和 1920x1080 下截图验证。
4. 是否存在按钮过小、文字重叠、表格溢出、角标遮挡。
5. hover、active、selected 边框是否与背景颜色协调。
6. 播放器暗色风格是否没有误用到主工具页面。
7. 未通过的项目必须先修复，不要继续新增页面。
