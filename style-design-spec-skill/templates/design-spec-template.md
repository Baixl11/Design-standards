## 16. 响应式规范

- 常用视口验证：390px / 430px 移动端、768px 平板、1440px 桌面端、1920px 大屏。
- 页面尺寸检查：不得出现横向溢出、内容超出父容器、卡片宽度不适配页面。
- 按钮尺寸检查：主按钮、图标按钮、底部导航项应有稳定宽高，移动端触控区域不小于 44px 高。
- 文字重叠检查：标题、正文、时间、角标、按钮文字、图标不得互相遮挡；列表项建议使用明确网格列或 minmax(0, 1fr) 防止挤压。
- 状态边框检查：hover / active / selected 边框应使用相近色系和低透明度，不得出现突兀高对比描边。
