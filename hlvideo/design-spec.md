## 3. 风格定位

视频取证工具的主界面是“浅色、专业、数据密集、取证可信”的桌面工作台风格。界面以白色和浅灰蓝为基础，通过明亮蓝色标识主操作、当前导航、选中项与可点击链接。整体不是营销型界面，而是面向高频作业的专业工具：导航明确、表格密集、筛选靠前、状态标签清晰、操作区固定。

播放器首页和播放器全屏界面是独立的暗色沉浸式场景。它使用黑色背景、紫蓝光感、红色播放按钮和产品宣传信息，不能直接混用到主工具工作台中。

## 4. 设计原则

1. 证据优先：文件、任务、路径、时间、哈希、分辨率、状态等取证信息必须优先清晰可读。
2. 操作可追踪：扫描、修复、分析、导出、哈希计算、OCR、时间校正等任务必须有明确入口、进度和结果反馈。
3. 密度克制：PC 桌面允许较高信息密度，但要通过浅底、细边框、分组标题和留白保持秩序。
4. 状态显性：正常、删除、失败、未完成、已挂载、任务进度、选中状态都应使用统一色彩与图标规则。
5. 选中不突兀：hover、active、selected 边框必须使用同色系或相近低对比颜色，禁止使用突兀高对比描边。
6. 尺寸可验证：页面开发后必须在 1366x768 和 1920x1080 等常见桌面尺寸下检查横向溢出、按钮挤压、文字重叠和角标覆盖。

## 10. 边框规范

| 类型 | 推荐值 | 用途 |
|---|---|---|
| 默认边框 | `1px solid #DCDFE6` | 输入框、表格、卡片 |
| 弱边框 | `1px solid #EBEEF5` | 表格行、轻分割 |
| 激活边框 | `1px solid #2194FF` | focus、选中卡片、选中分页 |
| hover 边框 | `1px solid #C9E4FF` 或 `#DCE2EC` | hover 卡片、弱交互 |
| 错误边框 | `1px solid #E34D59` | 表单错误、失败状态 |

选中/hover 规则：

- 选中卡片使用蓝色边框加浅蓝背景，例如磁盘任务选中态。
- hover 背景必须与默认背景相近，例如 `#ECF5FF`、`#F2F9FF`、`#F8FBFF`。
- 禁止黑色、纯红、纯紫等与当前组件语义无关的突兀描边。

## 11. 布局规范

### 11.1 主工具工作台

结构：

- 顶部标题栏：Logo、产品名、版本号、全局工具入口、窗口控制区。
- 左侧导航：扫描结果、文件系统、视频分析三个顶级 Tab，下面是记录名、概览、视频扫描结果、图片扫描结果、视频修复结果等树节点。
- 顶部工具栏：首页、刷新、导出文件、哈希计算、修复、分析、OCR 识别、时间校正、导出报告、挂载状态。
- 内容区：筛选条、表格/结果列表、详情区、底部批量操作区。

尺寸：

- 主设计画板以 1366x768 为基准，导出 PNG 多为 2732x1536，属于 2x 导出。
- 另有 1920x1080 大屏稿，必须支持宽屏内容扩展。
- 页面实现时以 `min-width: 1366px` 或可折叠布局保证桌面可用；小于 1366px 时必须使用侧边栏折叠、表格横向滚动或列隐藏策略。

### 11.2 报告阅读器

结构：

- 左侧报告目录树。
- 右侧报告内容区，以大标题、分割线、表格、分页、打印按钮组织。
- 表格密度比主工具略低，强调阅读和导出。

### 11.3 播放器

结构：

- 首页：暗色沉浸背景、品牌标题、打开按钮、能力介绍、产品试用入口。
- 播放页：视频画面优先，控制栏贴底，右键菜单和设置菜单以暗色浮层展示。

播放器暗色规范仅用于播放器，不能影响主工具浅色工作台。

## 12. 组件规范

### 12.1 Button 按钮

- 使用场景：主操作、表单提交、导出、打印、深度扫描、快速扫描、取消、打开。
- 默认样式：主按钮蓝底白字；次按钮白底灰边；危险按钮红色或红色文字；链接按钮蓝色文字。
- 尺寸：桌面小按钮 32px 高，中按钮 36px，高优先级按钮 40px。若用于触控或 Web 原型，点击区域不小于 44px。
- 圆角：2px 到 6px，主工具默认 4px 或 6px。
- hover：主按钮可加深或保持蓝色并增强明度，背景与边框同色系。
- disabled：低饱和灰底、灰字，不允许只降低透明度导致对比不足。
- 文本规则：按钮文字不换行；超过 6 个中文字时增加左右内边距或使用更宽按钮。
- 数据来源：真实采集与观察估算。

### 12.2 Input 输入框

- 高度：32px 到 36px。
- 默认：白底、`#DCDFE6` 边框、14px 正文。
- placeholder：`#C0C4CC`。
- focus：`#2194FF` 边框，必要时浅蓝外发光或背景。
- 错误：`#E34D59` 边框，下方 12px 错误说明。
- 长路径输入：保留完整值，显示层可使用中间省略，hover 展示完整路径。
- 数据来源：真实采集与观察估算。

### 12.3 Select 选择器

- 高度：32px 到 36px。
- 默认：白底、灰边、右侧下拉箭头。
- 展开浮层：白底、6px 圆角、轻阴影、选项 hover 浅蓝底。
- 当前值要有足够宽度，避免“通道：全部”等短标签与图标重叠。
- 数据来源：真实采集。

### 12.4 Table 表格

- 使用场景：扫描结果、视频列表、报告列表、任务列表、日志列表。
- 表头：浅灰背景，14px，文字灰色或一级文本，排序箭头使用弱灰。
- 行：白底、细分割线，hover 可使用极浅蓝或浅灰。
- 选中：复选框蓝色，选中行不必整行高饱和上色。
- 大字段：文件路径、文件名、详情字段必须支持省略、tooltip 或详情面板。
- 底部：分页、每页数量、跳转输入、批量操作固定在底部。
- 数据来源：真实采集。

### 12.5 Card 卡片

- 使用场景：磁盘设备、概览统计、功能入口、AI 设置项、播放器能力卡。
- 主工具卡片：白底、1px 灰边、6px 圆角。
- 选中卡片：浅蓝底、蓝色描边、右上角单选或勾选状态。
- hover：浅蓝或浅灰背景，不改变布局尺寸。
- 数据来源：真实采集。

### 12.6 Modal 弹窗

- 使用场景：创建任务、导出配置、任务失败、关闭提示、设置。
- 遮罩：深灰半透明，保持主体可识别但不可操作。
- 弹窗：白底、6px 到 8px 圆角、轻阴影，标题区和内容区分离。
- 底部操作：右对齐，主按钮在右，取消按钮在左或主按钮左侧。
- 表单弹窗必须检查底部按钮在 1366x768 下不被遮挡。
- 数据来源：真实采集。

### 12.7 Drawer 抽屉

- 当前视觉稿中抽屉不是主要形态。若新增详情抽屉，应从右侧进入，宽度建议 360px 到 480px，白底、左边框、顶部标题和关闭按钮。
- 数据来源：适配建议。

### 12.8 Tabs 标签页

- 顶级 Tab：扫描结果、文件系统、视频分析，文字 16px 左右，激活为蓝色。
- 内容 Tab：可使用 14px，激活用蓝色文字加底部线或浅蓝底。
- 分段控件：浅灰底，激活浅蓝底加蓝色文字。
- 数据来源：真实采集。

### 12.9 Tag 标签

- 状态标签：正常、未删除、已完成、未完成、失败、删除。
- 尺寸：高度 22px 到 26px，字号 12px 到 14px。
- 成功：浅绿底 + 绿色文字；信息：浅蓝底 + 蓝字；错误：浅红底 + 红字；警告：浅橙底 + 橙字。
- 数据来源：真实采集。

### 12.10 Alert 提示

- 使用场景：导出完成、任务失败、AI 引擎未安装、模型连接失败、容量不足。
- 样式：白底弹窗或浅色提示条，左侧状态图标，正文清晰说明，底部操作明确。
- 错误提示必须给出下一步操作，例如重试、检查配置、重新导入。
- 数据来源：PRD 真实采集。

### 12.11 Empty 空状态

- 使用场景：播放器暂无数据、分析结果暂无数据、上传空态、AI 识别空态。
- 样式：居中图标或轻插画，标题 16px，说明 14px，主操作按钮放在下方。
- 空状态不能占用过多高度导致首屏主操作不可见。
- 数据来源：真实采集。

### 12.12 Loading 加载态

- 使用场景：播放器加载中、磁盘信息加载中、上传中、AI 处理中、任务进度。
- 样式：进度条、百分比、旋转图标或“正在加载项目”文字。
- 任务型 loading 必须显示百分比或可取消/重试入口。
- 数据来源：真实采集。

### 12.13 Sidebar 侧边栏

- 宽度：约 266px。
- 背景：白色。
- 激活项：浅蓝背景、蓝色图标/文字或主文本加蓝色强调。
- 树节点：支持展开、收起、数量标识，长名称省略。
- 数据来源：真实采集。

### 12.14 Topbar 顶部栏

- 高度：约 56px。
- 内容：Logo、产品名、版本号、全局图标、窗口操作。
- 图标按钮：视觉尺寸约 20px 到 24px，点击区域建议不低于 32px；Web/触控场景不低于 44px。
- 角标：红底白字，必须与图标保持间距，不能压住正文。
- 数据来源：真实采集。

### 12.15 Form 表单

- 标签：14px，必填项用红色星号。
- 输入：统一 32px 到 36px 高。
- 三列布局适合宽弹窗，窄场景降为两列或一列。
- 路径选择采用输入框 + 选择按钮组合，按钮固定宽度。
- 数据来源：真实采集。

### 12.16 Dashboard 指标卡

- 使用场景：概览、视频结果、图片结果、日志结果。
- 样式：白底卡片，标题 16px，表格化字段或统计数值。
- 插画可用于概览右侧，但不能影响数据阅读。
- 数据来源：真实采集。

## 13. 页面模板规范

### 13.1 首页 / 概览

- 用途：展示检材基础信息、视频结果、图片结果、日志结果。
- 布局：左侧导航固定，右侧双列或多卡片概览。
- 重点：统计值、任务状态、进入扫描结果的入口。
- 数据来源：真实采集。

### 13.2 扫描结果页

- 用途：查看视频、图片、日志、修复结果。
- 布局：顶部工具栏 + 筛选条 + 表格 + 底部批量操作。
- 筛选：时间、通道、文件状态、内容查询、视图切换。
- 注意：表格列多时必须横向滚动，不能压缩到文字重叠。
- 数据来源：真实采集。

### 13.3 文件系统页

### 13.7 任务列表浮层

- 用途：查看后台任务进度、失败、取消、重启、查看。

- 数据来源：真实采集。

## 14. 交互规范

- hover：使用浅蓝或浅灰底，不能造成布局位移。
- active：按钮可略微加深，图标和文字颜色保持同体系。
- selected：使用蓝色文字/图标、浅蓝背景、蓝色边框，三者不必全部同时高强度出现。
- disabled：使用灰底、灰字、无 hover。
- loading：任务型 loading 必须显示进度、百分比或明确等待文案。
- error：错误提示必须说明问题和下一步，例如重新导入、检查配置、重试。
- long text：文件名、路径、任务名、报告名必须支持省略、tooltip 或详情展开。
- icon button：必须提供 hover 背景和可点击区域，不能只让图标本体可点。

## 15. 动效规范

- 常规 hover/focus：120ms 到 160ms。
- 弹窗、下拉、浮层：160ms 到 200ms。
- loading/进度条：线性或 ease-out，保持稳定，避免夸张弹跳。
- 播放器全屏控制栏：可使用淡入淡出，但不能遮挡视频关键区域。
- 数据来源：适配建议，视觉稿主要体现静态状态。

## 16. 响应式与尺寸适配规范

基准尺寸：

- 1366x768：主视觉稿最主要画板，必须完整可用。
- 1920x1080：大屏扩展稿，内容区可扩展但密度不应失控。
- 1280x720：若要支持低分辨率，需要折叠侧边栏或降低表格列显示。

检查要求：

- 页面不得出现横向内容被窗口裁切后无法访问的情况。
- 表格列过多时使用横向滚动、列固定、列隐藏或详情抽屉。
- 底部主按钮不得在 1366x768 下被遮挡。
- 弹窗高度超过视口时，内容区滚动，标题和底部按钮固定。
- 角标、浮层、tooltip 不得遮挡主文本。
- 按钮、图标按钮、导航项点击区域必须可见且稳定，不能因文字变化改变布局。
- Web 原型或后续 AI Coding 页面必须通过截图检查 1366x768、1440x900、1920x1080；若有移动端展示，再检查 390px 和 430px 宽度。

## 17. 前端实现建议

- 使用设计 token 管理颜色、字号、间距、圆角、阴影，不要在页面中散落硬编码样式。
- 主工具建议以 CSS Grid/Flex 实现固定 shell：titlebar、sidebar、toolbar、content、footer action。
- 表格建议使用可配置列宽、固定列、横向滚动和 tooltip。
- 选中、hover、active、disabled、loading 状态应作为组件变体，不要每页单独写。
- 深色播放器 token 应独立在 `dark-player` 或 `player` theme 下，避免污染主工具。
- 如果使用 Tailwind CSS，需要把 `#2194FF`、`#DCDFE6`、`#303133` 等写入主题扩展。
- 如果使用 Element Plus 或类似组件库，应覆盖主题变量，而不是直接覆盖每个组件内部 class。
