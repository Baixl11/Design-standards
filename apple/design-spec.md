# 苹果设计风格设计规范

## 1. 采集说明

- 目标对象：苹果设计风格
- 目标对象类型：抽象风格，参考 Apple 官方网站、Apple Developer 设计文档与设计资源页
- 采集日期：2026-06-26
- 采集方式：公开页面观察、DOM 样式读取、官方设计资源归纳
- 已采集页面：
  - Apple 官网首页：https://www.apple.com/
  - iPhone 产品页：https://www.apple.com/iphone/
  - Human Interface Guidelines：https://developer.apple.com/design/human-interface-guidelines/
  - Apple Design Resources：https://developer.apple.com/design/resources/
  - Apple Fonts：https://developer.apple.com/fonts/
  - SF Symbols：https://developer.apple.com/sf-symbols/
- 数据可信度：
  - 字体栈、正文颜色、深浅主题背景、部分标题字号、CTA 按钮样式为真实页面采集。
  - 卡片圆角、业务组件间距、后台/SaaS 页面模板为基于 Apple 风格的适配建议。
  - 状态色、表格、后台组件为项目适配建议，不是 Apple 官网原生页面直接采集。
- 使用限制：
  - 本规范只学习 Apple 的设计规律，不复制 Apple Logo、商标、产品图、专有插画、专有图标或品牌资产。
  - 如用于 iOS/macOS 原生应用，应优先以 Apple Human Interface Guidelines 和平台原生控件为准。

## 3. 风格定位

苹果设计风格的核心气质是：克制、清晰、精密、轻盈、以内容和产品为中心。

界面不靠复杂装饰建立高级感，而是通过充足留白、强信息层级、准确字体、干净背景、柔和层次、自然动效和高质量图像建立秩序。操作控件通常很少，但位置明确、触达直接。视觉强调优先服务内容本身，尤其是产品、功能结果、关键数据或主任务。

适合场景：

- 产品官网、品牌官网、硬件/软件发布页
- AI 工具、创作工具、效率工具、个人生产力产品
- 面向专业用户的 SaaS 或控制台
- 希望呈现高级、可信、轻量、现代感的 Web 应用
- 需要深浅主题兼容的跨平台界面

不适合直接套用的场景：

- 强促销、高密度运营位、电商货架页
- 极重数据表格和复杂审批流页面
- 需要大量彩色标签、强提醒和密集表单的传统后台

如果用于后台或企业 SaaS，需要保留 Apple 风格的清晰和克制，同时适当提高信息密度。

## 4. 设计原则

### 4.1 内容优先

- 页面第一视觉应服务核心内容，不让装饰元素抢走注意力。
- 关键标题、主图、主操作要清楚，辅助说明应安静。
- 不使用复杂纹理、重渐变、大面积装饰背景。

数据来源：Apple 官网和产品页真实观察，加项目适配建议。

### 4.2 层级明确

- 标题、说明、操作、辅助链接之间要有明显层级。
- 同一页面内避免超过 5 个常用字号层级。
- 使用字重、留白、透明度和色彩层级建立秩序。

数据来源：真实采集和适配建议。

### 4.3 轻量交互

- 操作状态应快速、安静、可预期。
- hover、active、focus、loading、disabled 都要完整。
- 动效短、柔和，不制造炫技感。

数据来源：Apple HIG 方向归纳，具体动效数值为适配建议。

### 4.4 视觉中性

- 主体以黑、白、灰为骨架。
- 品牌强调色少量使用，优先用于 CTA、选中态、链接和关键反馈。
- 避免大面积高饱和色块。

数据来源：Apple 官网与 Developer 页面真实观察。

## 5. 色彩系统

### 5.1 主色

- 主色：`#0071E3`
- 用途：主按钮、主链接、激活状态、关键操作
- 页面采集：iPhone 产品页主体 CTA 按钮背景为 `rgb(0, 113, 227)`
- 数据来源：真实采集

### 5.2 主色状态

- Hover：`#0077ED`
- Active：`#006EDB`
- Light：`#E8F2FF`
- Focus ring：`rgba(0, 113, 227, 0.35)`
- 数据来源：基于真实主色的适配建议

### 5.3 中性色

- 页面浅色背景：`#FFFFFF`
- 次级浅色背景：`#F5F5F7`
- 卡片背景：`#FFFFFF`
- 深色背景：`#000000`
- 深色抬升背景：`#161617`
- 主文本浅色模式：`#1D1D1F`
- 次级文本浅色模式：`#6E6E73`
- 弱文本浅色模式：`#86868B`
- 深色模式主文本：`#F5F5F7`
- 深色模式次级文本：`#86868B`
- 导航文本：`rgba(0, 0, 0, 0.8)`
- 数据来源：Apple 官网、Developer 页面真实采集

### 5.4 边框与分割线

- 默认边框：`#D2D2D7`
- 弱边框：`#E8E8ED`
- 深色边框：`rgba(255, 255, 255, 0.16)`
- 分割线：`rgba(0, 0, 0, 0.12)`
- 数据来源：Apple 页面风格观察和项目适配建议

### 5.5 状态色

- 成功：`#34C759`
- 警告：`#FF9500`
- 错误：`#FF3B30`
- 信息：`#007AFF`
- 数据来源：Apple 平台系统色方向的项目适配建议，Web 项目应按品牌和可访问性复核。

### 5.6 使用规则

- 页面 70% 以上区域应由白、黑、灰组成。
- 主色只用于真正可点击、选中、强调的信息。
- 不在同一页面同时使用多个强品牌色。
- 深色模式下不要直接反相所有颜色，应重新定义文本、背景和边框透明度。

## 6. 字体系统

### 6.1 字体家族

Web 推荐：

```css
font-family:
  "SF Pro Text",
  "SF Pro Icons",
  -apple-system,
  BlinkMacSystemFont,
  "Helvetica Neue",
  Helvetica,
  Arial,
  "PingFang SC",
  "Microsoft YaHei",
  sans-serif;
```

标题可优先使用：

```css
font-family:
  "SF Pro Display",
  "SF Pro Text",
  -apple-system,
  BlinkMacSystemFont,
  "Helvetica Neue",
  Helvetica,
  Arial,
  "PingFang SC",
  sans-serif;
```

数据来源：Apple 官网和 Developer 页面真实采集到 `SF Pro Text`、`SF Pro Icons`、`Helvetica Neue`、Helvetica、Arial、sans-serif 字体栈；中文字体为项目适配建议。

### 6.2 字号层级

| 层级 | 推荐值 | 使用场景 | 数据来源 |
|---|---:|---|---|
| Caption | 12px / 16px | 导航、脚注、弱辅助信息 | 真实采集 |
| Small | 14px / 20px | 表单说明、标签、表格辅助列 | 适配建议 |
| Body | 17px / 25px | 正文、按钮、主要说明 | 真实采集 |
| Body Large | 21px / 28px | 重点说明、营销副标题 | 真实采集和适配建议 |
| Title Small | 24px / 28px | 卡片标题、菜单大项 | 真实采集 |
| Title | 28px / 32px | 模块标题、折叠面板标题 | 真实采集 |
| Section Title | 32px / 36px | 页面分区标题 | 真实采集 |
| Hero | 48px / 52px | 首屏主标题、品牌表达 | 真实采集 |
| Display | 56px / 64px | 营销页大标题 | 观察估算和适配建议 |

### 6.3 字重

- 标题：600 / 700
- 正文：400
- 强调正文：500 / 600
- 导航：400
- 按钮：400 / 500

数据来源：真实采集和适配建议。

### 6.4 排版规则

- 字距保持 `0`，不要为了模仿营销页随意设置负字距。
- 标题应短，避免多行大段口号。
- 中文界面中，正文建议 16px 或 17px；后台类产品建议 14px 到 16px。
- 主标题和正文之间需要足够留白，不靠边框分隔。

## 7. 间距系统

基础单位：4px，主要节奏使用 8px。

| Token | 值 | 用途 |
|---|---:|---|
| 1 | 4px | 极小间隔 |
| 2 | 8px | 图标和文字间距 |
| 3 | 12px | 小控件内距 |
| 4 | 16px | 默认组件间距 |
| 5 | 20px | 按钮横向补充间距 |
| 6 | 24px | 卡片内距、区块内距 |
| 8 | 32px | 模块间距 |
| 10 | 40px | 页面分区间距 |
| 12 | 48px | 大区块间距 |
| 16 | 64px | 营销页首屏分区 |
| 20 | 80px | 大屏页面上下留白 |

推荐：

- 页面外边距：24px / 40px / 64px
- 营销页区块上下留白：64px 到 120px
- 应用页区块间距：24px 到 40px
- 卡片内边距：24px / 32px
- 表单项间距：16px
- 按钮内边距：约 11px 21px，真实采集自 iPhone 页 CTA
- 表格单元格内边距：12px 16px，项目适配建议

## 8. 圆角系统

| 类型 | 推荐值 | 用途 | 数据来源 |
|---|---:|---|---|
| 小圆角 | 8px | Tag、小输入框、轻量按钮 | 适配建议 |
| 中圆角 | 12px | 输入框、普通卡片、菜单 | 适配建议 |
| 大圆角 | 18px | 信息卡、弹窗、重点模块 | 观察估算和适配建议 |
| 超大圆角 | 24px / 28px | 大卡片、营销模块 | 观察估算和适配建议 |
| 胶囊圆角 | 999px | 主按钮、圆形/胶囊控件 | 真实采集，Apple CTA 为 980px |

使用规则：

- 主按钮优先使用胶囊形态。
- 后台表格或高密度界面可以降低圆角到 8px 或 10px。
- 不在同一模块混用过多圆角值。

## 9. 阴影系统

Apple 风格不依赖重阴影建立层级。优先通过背景色、留白、边框和内容层级完成区分。

推荐阴影：

- 默认卡片：无阴影或极轻阴影
- 悬浮卡片：`0 8px 24px rgba(0, 0, 0, 0.08)`
- 弹窗：`0 18px 60px rgba(0, 0, 0, 0.18)`
- 深色模式弹窗：`0 24px 80px rgba(0, 0, 0, 0.48)`

数据来源：页面观察和项目适配建议。

## 10. 边框规范

- 普通卡片：可无边框，使用背景层级区分。
- 表单输入：`1px solid #D2D2D7`
- 表格分割线：`1px solid #E8E8ED`
- Focus：主色边框加柔和外发光。
- 深色模式：使用半透明白色边框，不使用纯白线。

## 11. 布局规范

### 11.1 官网 / 营销页

- 顶部导航轻量、低高度、低对比，建议 44px 到 52px。
- 首屏内容居中，标题、说明、CTA 与产品图形成垂直主轴。
- 大屏要有明显留白，不把内容塞满。
- 图片或产品展示应是页面主角。
- 多个产品卡片应保持统一网格和对齐。

数据来源：Apple 官网与 iPhone 页面观察。

### 11.2 Web 应用 / SaaS

- 以内容和任务效率为中心，减少营销页式巨大留白。
- 建议使用轻量 topbar + 主内容区，复杂产品可增加 sidebar。
- 页面背景使用 `#F5F5F7`，内容卡片使用白色。
- 操作区应清楚，不把主按钮隐藏在弱链接中。
- 表格页可以提高密度，但仍要保持干净边界和清晰行距。

数据来源：Apple 风格适配建议。

### 11.3 响应式

- 桌面端：最大内容宽度可使用 980px / 1200px / 1440px。
- 平板端：保留主内容优先级，侧边栏可折叠。
- 移动端：单列布局，按钮宽度可自适应，不产生横向滚动。
- 大标题在移动端需要降级，避免压缩到难读。

## 12. 组件规范

### 12.1 Button 按钮

- 使用场景：主 CTA、关键提交、次级操作、文本链接。
- 主按钮：
  - 背景：`#0071E3`
  - 文字：`#FFFFFF`
  - 字号：17px
  - 内边距：11px 21px
  - 圆角：999px
  - 数据来源：iPhone 页面真实采集
- 中性按钮：
  - 背景：`#1D1D1F`
  - 文字：`#FFFFFF`
  - 数据来源：iPhone 页面真实采集到中性视频 CTA
- 次级按钮：
  - 背景：透明或 `#F5F5F7`
  - 文字：`#0071E3` 或 `#1D1D1F`
  - 边框：可选 `#D2D2D7`
  - 数据来源：适配建议
- 状态：
  - hover：轻微提亮或降低透明度
  - active：轻微压暗
  - disabled：文字和背景降级，禁止只靠透明度导致不可读
  - loading：保留按钮宽度，显示 spinner 或进度文本
- 尺寸与适配：
  - 移动端主要触控按钮点击区域不小于 44px 高。
  - 底部导航、图标按钮和胶囊按钮必须有稳定宽高，不能因选中态、未读角标或文字变化导致布局跳动。
  - 选中态和 hover 态边框应使用与背景相近的低透明主色，例如 `rgba(0, 113, 227, 0.10)` 到 `rgba(0, 113, 227, 0.18)`，避免突兀的高对比描边。
  - 按钮文字必须完整显示；如果空间不足，应缩短标签、换行到明确两行或使用 icon-only + tooltip，不允许文字挤压重叠。

### 12.2 Input 输入框

- 高度：44px 到 48px
- 背景：`#FFFFFF`
- 边框：`#D2D2D7`
- 圆角：12px
- 字号：16px / 17px
- Focus：`#0071E3` 边框和柔和 focus ring
- 错误：边框 `#FF3B30`，错误文字 13px 到 14px
- 数据来源：项目适配建议

### 12.3 Select 选择器

- 与 Input 同高同圆角。
- 右侧使用简洁下箭头或系统图标。
- 选中项颜色使用主文本，不用大面积蓝底。
- 菜单浮层圆角 14px 到 18px，阴影克制。
- 数据来源：项目适配建议

### 12.4 Table 表格

- 表头：12px 到 14px，字重 600，颜色 `#6E6E73`
- 单元格：14px 到 15px，行高 20px 到 22px
- 行高：44px 到 52px
- 分割线：`#E8E8ED`
- Hover：`#F5F5F7`
- 选中：浅蓝 `#E8F2FF`
- 数据来源：项目适配建议

### 12.5 Card 卡片

- 背景：`#FFFFFF`
- 圆角：18px 到 24px
- 内边距：24px / 32px
- 阴影：默认不用，hover 可轻微阴影
- 边框：可选 `#E8E8ED`
- 信息结构：标题、核心内容、辅助说明、操作区，不堆叠过多标签
- 数据来源：Apple 产品页观察和项目适配建议

### 12.6 Modal 弹窗

- 宽度：480px / 640px / 720px，按内容选择
- 圆角：20px 到 24px
- 背景：浅色 `#FFFFFF`，深色 `#161617`
- 遮罩：`rgba(0, 0, 0, 0.32)`
- 内边距：24px / 32px
- 关闭按钮：右上角图标按钮，点击区至少 40px
- 数据来源：项目适配建议

### 12.7 Drawer 抽屉

- 适合设置、详情、筛选。
- 宽度：360px 到 520px。
- 背景保持干净，不使用强边框。
- 顶部标题固定，底部操作固定，内容区滚动。
- 数据来源：项目适配建议

### 12.8 Tabs 标签页

- 使用轻量文本标签或胶囊分段控件。
- 激活态使用主文本或主色，不使用重色块。
- 下划线高度 2px，圆角 999px。
- 分段控件背景可用 `#F5F5F7`，激活项白底轻阴影。
- 数据来源：Apple 平台控件风格归纳和项目适配建议

### 12.9 Tag 标签

- 高度：24px 到 28px
- 圆角：999px 或 8px
- 背景：`#F5F5F7`
- 文字：`#6E6E73`
- 状态标签可使用低饱和浅底，不用高饱和实底。
- 数据来源：项目适配建议

### 12.10 Alert 提示

- 成功、警告、错误、信息都需要图标和文字。
- 背景使用浅色状态底，文本保持高对比。
- 不用大面积高饱和色块。
- 可关闭提示需要明确关闭按钮。
- 数据来源：项目适配建议

### 12.11 Empty 空状态

- 使用简洁图标或轻量插图。
- 文案短，说明当前状态和下一步动作。
- 主操作使用主按钮，次操作使用文本链接。
- 不使用复杂大插画。
- 数据来源：项目适配建议

### 12.12 Loading 加载态

- 局部加载优先 skeleton 或小 spinner。
- 全页加载应保持页面框架，避免空白等待。
- 按钮 loading 不改变按钮宽度。
- 数据来源：项目适配建议

### 12.13 Sidebar 侧边栏

- 宽度：240px 到 280px。
- 背景：`#FFFFFF` 或 `#F5F5F7`。
- 导航项高度：40px 到 44px。
- 激活态：浅蓝背景或浅灰背景加主色文字。
- 图标使用线性图标，大小 18px 到 20px。
- 数据来源：Apple 风格适配到 SaaS 的建议

### 12.14 Topbar 顶部栏

- 高度：44px 到 56px。
- 背景可以使用半透明白或纯白。
- 文本小而清晰，导航项 12px 到 14px。
- 页面内应用不建议完全照搬 Apple 官网 12px 导航，业务系统可升至 14px。
- 数据来源：Apple 官网真实采集和适配建议

### 12.15 Form 表单

- 标签 14px，说明 13px，输入 16px / 17px。
- 表单项间距 16px，分组间距 32px。
- 错误提示紧贴字段下方。
- 主提交按钮放在自然完成路径末尾。
- 数据来源：项目适配建议

### 12.16 Dashboard 指标卡

- 指标数字使用 28px 到 40px，字重 600。
- 次级说明使用 13px 到 14px 灰色文字。
- 趋势色只在必要处使用。
- 卡片保持低装饰，不使用大面积彩色背景。
- 数据来源：项目适配建议

## 13. 页面模板规范

### 13.1 产品官网首页

- 首屏：轻量导航、中心标题、简短副标题、1 到 2 个 CTA、主体产品图。
- 第二屏：产品能力卡片或核心卖点，保持大留白。
- 内容分区：每屏只表达一个主概念。
- 注意：不要把所有卖点放进首屏。

### 13.2 SaaS 控制台首页

- 顶部：页面标题、时间范围、关键操作。
- 主体：指标卡、趋势图、任务列表、最近活动。
- 背景：`#F5F5F7`，卡片白底。
- 注意：控制台要比官网更紧凑。

### 13.3 列表管理页

- 顶部：标题、说明、主按钮。
- 工具区：搜索、筛选、批量操作。
- 表格：清晰列宽、弱分割线、行 hover。
- 分页：右下或底部固定区域。

### 13.4 详情页

- 顶部：返回、标题、状态、主要操作。
- 主体：信息分组卡片，少用边框，多用留白。
- 侧栏：可放关键元信息或快捷操作。

### 13.5 表单创建页

- 单列优先，复杂表单分组。
- 关键说明放在字段附近，不放到页面顶部。
- 底部操作清楚，主按钮只有一个。

### 13.6 设置页

- 左侧分类，右侧内容。
- 每个设置项有标题、说明和控件。
- 危险操作单独分组，使用明确警示。

## 14. 交互规范

- Hover：轻微背景变化或文本颜色变化，不剧烈跳动。
- Active：按钮轻微压暗，卡片可轻微下沉。
- Focus：必须可见，建议主色 focus ring。
- Disabled：保持可读，不能只用很低透明度。
- Loading：局部反馈优先，不阻断整页。
- Empty：说明状态，并给出下一步。
- Error：指出原因和修复方式。
- Success：短反馈即可，避免持续占用视觉中心。

## 15. 动效规范

- 常规过渡：160ms 到 220ms
- 浮层进入：200ms 到 260ms
- 页面大区域切换：240ms 到 320ms
- 缓动：`cubic-bezier(0.2, 0, 0, 1)` 或 `ease-out`
- 原则：动效服务方向感、层级和反馈，不做无意义装饰。

数据来源：Apple HIG 设计方向归纳和项目适配建议。

## 16. 响应式规范

- 1440px 桌面端：内容最大宽度建议 1200px 到 1440px。
- 1920px 大屏：增加边距，不无限拉伸卡片。
- 1024px 平板：侧栏可折叠，卡片改为两列或单列。
- 768px 以下：主内容单列，表格使用横向滚动或卡片化。
- 480px 以下：大标题降级，按钮可全宽，避免横向溢出。
- 必须在目标页面常用视口下验证组件真实尺寸，包括 390px / 430px 移动宽度、768px 平板、1440px 桌面和 1920px 大屏。
- 卡片、消息列表、底部导航、顶部栏、按钮组和表单项都必须检查：内容宽度是否适配父容器、文字是否截断合理、图标/角标是否挤压主体文本。
- 对于列表项，推荐使用明确网格列或 `minmax(0, 1fr)` 的弹性布局，确保中间文本可以省略而不是把时间、角标或操作按钮挤出容器。
- 所有固定格式 UI 元素都需要稳定尺寸，例如导航项、图标按钮、计数徽标、媒体卡、输入框和主按钮；hover、active、selected、loading 状态不得改变布局尺寸。

## 17. 前端实现建议

- 优先将颜色、字号、间距、圆角和阴影写入 token。
- 使用 CSS variables 支持深浅主题。
- 使用系统字体栈，不强制用户下载 Apple 字体。
- 图标使用 SF Symbols 风格的线性图标体系，但不要直接复制 Apple 专有符号资源到非授权项目。
- Web 项目可使用 lucide、Material Symbols 或自有图标库做风格适配：线条统一、端点圆润、尺寸一致。
- 不在业务页面里散落硬编码颜色和间距。
- 组件应先复用，再扩展。
- 实现后必须做视觉 QA：检查所有页面在移动和桌面视口下是否存在横向溢出、文字遮挡、按钮挤压、角标覆盖、选中态边框过重或内容超出父容器。
- 对于复杂列表和底部导航，优先使用 CSS Grid 或稳定尺寸约束，不依赖内容自然宽度撑开布局。
